# Fixora – Project Management System

## 1. Introduction

**Fixora** is a web-based Project Management System developed to make project planning, team collaboration, and task management easier and more organized.

The application provides a centralized platform where users can manage projects, organize tickets, assign tasks, monitor progress, and collaborate through comments.

The main objective of Fixora is to simplify project management by bringing important project-related activities together in one place.

## 2. Technology Stack and Reasons for Choosing It

Fixora is developed using the **MERN Stack**, which combines MongoDB, Express.js, React.js, and Node.js.

| Technology | Purpose | Reason for Choosing |
|---|---|---|
| MongoDB | Database | Stores application data in a flexible document-based format. |
| Express.js | Backend framework | Helps build APIs and manage server-side routes. |
| React.js | Frontend library | Supports reusable components and interactive user interfaces. |
| Node.js | Runtime environment | Allows JavaScript to run on the server side. |
| CSS | Styling | Used to create the application's visual design and layout. |

### Why the MERN Stack?

- It allows JavaScript to be used across frontend and backend development.
- React makes it easier to build reusable UI components.
- Node.js and Express.js support backend API development.
- MongoDB provides flexible data storage.
- The technologies work together to create a full-stack web application.

## 3. Use Cases

The major use cases of Fixora are:

### 3.1 User Authentication
Users can register and log in to access the application securely.

### 3.2 Dashboard
Users can view an overview of their projects, tickets, and overall work progress.

### 3.3 Project Management
Users can create, view, and manage projects from a centralized dashboard.

### 3.4 Team Management
The system supports team collaboration and organizing project members.

### 3.5 Ticket Management
Users can create, view, update, and manage tickets related to their work.

### 3.6 Ticket Assignment
Tickets can be assigned to team members to organize responsibilities.

### 3.7 Priority and Status Management
Users can manage ticket priorities and track their current status.

### 3.8 Kanban Board
The Kanban board provides a visual representation of tasks and their progress.

### 3.9 Comments
Users can add comments to tickets to support communication and collaboration.

### 3.10 Profile Management
Users can view and manage their profile information.

## 4. Research and Analysis

Before developing Fixora, the project requirements and common project management workflows were considered.

The research and analysis focused on the following areas:

- Understanding the need for centralized project management.
- Identifying the importance of task assignment and tracking.
- Understanding how ticket priorities and statuses help organize work.
- Studying how Kanban boards visually represent workflow progress.
- Identifying the role of team collaboration and communication.
- Selecting a suitable technology stack for developing a full-stack application.

Based on these considerations, Fixora was designed to combine project management, ticket tracking, and team collaboration in one application.

## 6. Conclusion

Fixora was developed to provide a simple and organized solution for project management and team collaboration.
